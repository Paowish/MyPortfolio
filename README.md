# Student portfolio

A minimal one-page portfolio built with React, Vite and Tailwind CSS.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Make it yours

All content lives in the `DATA` object at the top of `src/App.jsx`:
name, intro, stats, projects, education, skills, certifications,
recommendations, activities and social links. Everything shown is sample
content until you replace it.

Colors and fonts are CSS variables at the top of `src/index.css`.
The light and dark themes both follow the visitor's system setting, and the
header button overrides it.

Shortcuts: Cmd/Ctrl + K opens the jump-to palette, Cmd/Ctrl + J opens the typing test.

The activity heatmap is generated sample data. Replace it with real data
(for example from the GitHub API) when you are ready.
